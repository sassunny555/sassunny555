# Profile assets

The banner was created with the built-in OpenAI image generation tool. The link badges and project cards are original SVG artwork. Technology icons were downloaded from [Skill Icons](https://github.com/tandpfun/skill-icons) and are distributed under its MIT license (see `SKILL-ICONS-LICENSE`).

Project and biography copy is based on the public SunnyDevLabs portfolio and the public SnapFit and LeadFinder repositories. Only this profile repository is customized.

Live statistics use GitHub Readme Stats and GitHub Readme Streak Stats. These third-party services cache data and may occasionally be unavailable. The banner, buttons, project cards, and technology icons are stored in this repository.
